# Claude_Mods

Mods for [Claude Code](https://claude.com/claude-code). Each folder is one mod.

| Mod | What it does |
| --- | --- |
| [all-prompts](all-prompts/) | A column on the right listing your prompts from every Claude Code session, with the session each was typed in |
| [prompt-jump](prompt-jump/) | option+k / option+j jump the transcript to your previous / next prompt (needs two keybindings; see its README) |

## Install

Type this at the prompt of a Claude Code terminal session, naming the mod:

```
/plugin install all-prompts --marketplace gvarnell/Claude_Mods
```

Answer `y` to add the marketplace, then press Enter to install it at the user
scope. It runs in that session right away, and in every session you start after.
